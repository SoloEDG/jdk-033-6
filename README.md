## 起跑指令规划（features/startline）

针对“两条训练艇抢风位、陪练在允许时刻中择一换舷”的出发问题，给出可跟着做的分支起跑指令：

- **因果分支**：陪练换舷在船首转过迎风后才视为可见；分支指令不得早于“观测时刻 + 0.5 s 反应延迟”。
  观测历史相同的情形在相同时刻收到完全相同的指令，规划器会检测并标记任何相反指令。
- **风影模型**：每条训练艇持续发射风影团，旧风影只向下风漂移并在 1.3 s 后衰减；
  每条船取最强风影、总风速亏损封顶 55%，因此重叠时风速也不会反向。
- **OCS 规则**：枪响前越线记一次 OCS，自动顺风退回起线后方，重新加速后再过线才计成绩。
- **三分类裁决**：`full`（全部允许情形及时合法过线且无因果冲突）、
  `partial`（仅部分情形合法，列出失败情形）、`unknown`（无任何情形成功或存在未消解冲突）。
- 事件时间线保留每条指令、信念更新、风影进出、OCS 与折返、合法过线，回看可追溯指令为何改变、空等或折返。
